    Environment Variables

    Every variable Core reads in its default configuration, grouped by the top-level config key it sets. Set a variable in .env or the process environment to change the default; set the config path in your application Config to override it in code. The default column shows the source expression: a nested Env::get() is a fallback variable, and constants such as APP_PATH are resolved at bootstrap.

    Core reads 625 variables in 38 sections.

    Path Constants

    Core defines these constants before it builds the config, unless your bootstrap already defined them (the App skeleton does, in bootstrap.php).

    Constant Variable Default
    ROOT_PATH ROOT_PATH (getcwd() ?: '.') . '/'
    VENDOR_PATH VENDOR_PATH ROOT_PATH . 'vendor/'
    CORE_PATH CORE_PATH mb_substr(__DIR__, 0, mb_strlen(basename(__DIR__)) * -1)
